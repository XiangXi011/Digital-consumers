# FP 与 M 画像映射表

## 牙釉质修护类
- `FP01 敏感修护焦虑型` → `M02` 高意识研究比较型，`M04` 一般意识品牌筛选型
- `FP02 健康投资理性型` → `M01` 高意识品牌忠诚型，`M02` 高意识研究比较型
- `FP03 成分/专业背书关注型` → `M03` 一般意识功效导向型，`M04` 一般意识品牌筛选型
- `FP04 医美/正畸后恢复型` → `M02` 高意识研究比较型，`M07` 全能优等家

## 遮瑕美白类
- `FP05 上镜急救型` → `M03` 一般意识功效导向型，`M05` 低意识冲动购买型
- `FP06 美妆联想型` → `M03` 一般意识功效导向型，`M06` 低意识渠道依赖型
- `FP07 咖啡茶饮牙黄补救型` → `M05` 低意识冲动购买型，`M08` 佛系粗养家
- `FP08 价格敏感但想变白型` → `M05` 低意识冲动购买型，`M08` 佛系粗养家

## 使用建议
- `FP` 画像用于新品类业务表达、营销定位、素材策划
- `M` 画像用于系统推理、决策权重、veto 和评分逻辑
- 在需要自动化时，优先使用 `FP` 的业务语义，回落到 `M` 的决策结构
