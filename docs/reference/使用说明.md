# 钉钉妈妈定性研究 Agent 使用说明

## 1. 项目用途

这个项目是一个运行在钉钉群聊里的市场研究 Agent。

它的核心能力是：

- 在钉钉群里收集研究任务信息
- 把用户输入整理成结构化 `BusinessBrief`
- 调用 8 类妈妈画像做定性研究
- 生成简版结论
- 产出本地 HTML / JSON 报告
- 在配置正常时尝试发布 HTML 公网链接

当前最新版本已经接入：

- `BusinessBrief` 隔离
- `ReadinessGate` 统一判定
- follow-up arbitration
- dispatch 期间补充消息暂存
- frozen snapshot / metrics / 隐私脱敏

## 2. 当前推荐运行方式

当前机器上的系统 Python 是 `3.14`，而钉钉 `dingtalk-stream + websockets` 在这个组合下不稳定。

最新可用方案是：

- 使用项目专用环境：`.venv-dingtalk310`
- 使用 `Python 3.10`
- 通过 PowerShell 启动脚本运行钉钉 stream 服务

不要直接用系统自带的 `python run_dingtalk_stream_bot.py`。

## 5. 首次准备

如果这台机器还没有 `Python 3.10`，先安装它。

然后在项目根目录执行：

```powershell
py -3.10 -m venv .venv-dingtalk310
```

再安装当前运行依赖：

```powershell
.\.venv-dingtalk310\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.\.venv-dingtalk310\Scripts\python.exe -m pip install langgraph==1.0.10 openai==2.24.0 pydantic==2.12.5 langsmith==0.7.16 requests==2.32.5 aiohttp==3.13.3 dingtalk-stream==0.24.3 websockets==15.0.1 pyyaml pillow
```

如果后续 `ai_clients.py` 新增依赖，也要同步装到这个环境里。

## 6. 启动服务

在项目根目录执行：

```powershell

```

这个脚本会自动完成：

- 使用 `.venv-dingtalk310`
- 杀掉旧的 `run_dingtalk_stream_bot.py` 进程
- 启动新的钉钉 stream 服务
- 把 PID 写入日志目录
- 输出 stdout / stderr 日志路径

启动成功后，重点查看：

## 7. 停止服务

```powershell

```

这个脚本会：

- 优先按 PID 文件停止当前 live 进程
- 再兜底清理所有 `run_dingtalk_stream_bot.py` 相关进程

## 8. 在钉钉里怎么用

### 8.1 发起任务

在群里 `@机器人`，先发一个研究需求即可。

机器人会先回一份“研究任务信息清单”，然后你可以分多条补充，也可以一次发完整。

### 8.2 建议输入字段

推荐尽量明确这些字段：

- `模式`：`单人` / `多人`
- `研究问题`：如 `购买决策`、`文案和卖点反馈`、`A/B测试`、`价格测试`
- `指定妈妈画像`：单人模式时填写，如 `M04`
- `用户问题`
- `产品信息`
- `文案或卖点`

价格测试建议再补：

- `价格测试方式`
- `价格区间`
- `对标参考`
- `规格或容量`
- `价格锚点类型`

### 8.3 直接可用的完整示例

```text
@机器人
模式：多人
研究问题：购买决策
用户问题：这款儿童牙膏 8 类妈妈会不会买，最大的顾虑是什么？
产品信息：儿童牙膏，主打低氟防蛀、孩子更愿意坚持刷牙。
文案或卖点：专业防蛀，孩子喜欢，妈妈省心。
```

单人模式示例：

```text
@机器人
模式：单人
研究问题：文案和卖点反馈
指定妈妈画像：M04
用户问题：高线忙碌妈妈会不会被这句文案打动？
产品信息：儿童牙膏
文案或卖点：专业防蛀，孩子更喜欢刷牙，妈妈更省心。
```

### 8.4 触发正式运行

当信息补齐后，直接回复：

```text
按当前信息运行
```

系统会进入：

- readiness 判定
- planner
- persona dispatch
- synthesis
- 报告写入

### 8.5 运行中补充信息

如果任务已经在跑，你又发了新消息：

- 新消息不会直接覆盖当前任务
- 会进入 suspend queue 暂存
- 当前任务结束后，机器人会提醒你还有补充消息可继续评估

## 9. 输出结果说明

### 9.1 钉钉里会收到什么

通常会收到两类结果：

- 一条“开始生成”的提示
- 一条简版结论

如果 HTML 公网链接可用，还会附带一个 HTML 报告链接。

### 9.2 本地文件落在哪里

每次任务通常会生成：

- `outputs/dingtalk_reports/*.html`
- `outputs/dingtalk_reports/*.json`
- `outputs/dingtalk_sessions/*.json`
- `metrics/*.json`
- `snapshots/live/*.json`
- `snapshots/frozen/*.json`

## 10. 常见问题排查

### 10.1 钉钉里没有响应

先检查服务是否在跑：

```powershell
Get-CimInstance Win32_Process | Where-Object { $_.Name -match '^python(\.exe)?$' -and $_.CommandLine -match 'run_dingtalk_stream_bot\.py' }
```

再看日志：

- [dingtalk_stream_live_current_stderr.log](C:/Users/05537/Desktop/agent/市场部agent%20teams/outputs/logs/dingtalk_stream_live_current_stderr.log)

### 10.2 服务一启动就退出

常见原因：

- `.env` 缺少 `DINGTALK_APP_KEY` / `DINGTALK_APP_SECRET`
- `.env` 缺少 `OPENAI_API_KEY`
- `.venv-dingtalk310` 里缺包
- 误用了系统 Python 3.14

### 10.3 钉钉连上了，但运行任务失败

优先看：

- [dingtalk_stream_live_current_stderr.log](C:/Users/05537/Desktop/agent/市场部agent%20teams/outputs/logs/dingtalk_stream_live_current_stderr.log)
- [outputs/dingtalk_sessions](C:/Users/05537/Desktop/agent/市场部agent%20teams/outputs/dingtalk_sessions)

如果是业务层问题，通常会在会话 JSON 里看到：

- `status`
- `business_brief`
- `readiness_decision`
- `research_plan`

### 10.4 HTML 外链没回来

当前版本里，Vercel 自动发布偶发网络抖动，报错表现通常是：

- `api.vercel.com`
- `ECONNRESET`

这时：

- 钉钉里的简版结论通常仍然可用
- 本地 HTML 报告仍然已经生成
- 你可以直接从 [outputs/dingtalk_reports](C:/Users/05537/Desktop/agent/市场部agent%20teams/outputs/dingtalk_reports) 打开 HTML
