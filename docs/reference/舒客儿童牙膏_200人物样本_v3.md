## 使用说明

### 样本结构
每个样本包含以下字段：
- **基础信息**：姓名、年龄、城市、职业、收入
- **家庭结构**：孩子年龄、家庭构成、居住情况
- **消费特征**：主要渠道、购买频率、预算范围
- **口腔状况**：孩子/家长口腔问题
- **决策权重**：8个因素的优先级排序
- **表达风格**：沟通类型、平台偏好、典型话术
- **行为约束**：可见/不可见信息边界
- **产品评分**：1-10分评估
- **购买决策**：会买/犹豫/不会买
- **原话模拟**：真实口吻的用户反馈

### 随机性说明
- 姓名、年龄、城市、职业等基础信息随机生成
- 决策偏好遵循人群画像的核心特征，但有细微差异
- 评分在人群基准分±1分范围内波动
- 所有样本均符合该人群的"行为约束"边界
