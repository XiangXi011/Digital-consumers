## 快速使用

### 查看已有报告
直接打开对应的 `.md` 文件即可查看完整评估结果。

**推荐查看最新版v2.0报告**，包含完整的5维用户画像框架。

### 评估新产品
1. 参考 `评估模板_可复用_v2.md` 了解流程
2. 使用以下提示词启动评估：

```
使用v2.0评估模板，对[产品名]进行多人群评估。

产品信息：
- 名称：
- 价格：
- 包装可见信息：
- 销售渠道：

需要评估的人群（请为每个画像填写5维框架）：
1. [人群1名称]
2. [人群2名称]
...
```
